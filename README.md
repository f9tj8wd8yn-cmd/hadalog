# HadaLog 公開手順

このフォルダの中身（`index.html` / `manifest.webmanifest` / `icon.svg`）だけを置けば動きます。サーバー処理はありません。データはそれぞれの端末の中に保存されます。

## 方法A：Netlify Drop（いちばん簡単）

1. https://app.netlify.com/drop を開く（Netlify のアカウントが必要）
2. この `deploy` フォルダを、画面にドラッグ＆ドロップ
3. 発行された URL（例：`https://xxxx.netlify.app`）をスマホで開く

## 方法B：GitHub Pages

1. GitHub でリポジトリを作り、`deploy` の中身をアップロード
2. Settings → Pages → Source を `main` ブランチのルートに設定
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

## スマホでの確認

- iPhone：Safari で開く → 共有ボタン → 「ホーム画面に追加」
- Android：Chrome で開く → メニュー → 「ホーム画面に追加」

ホーム画面から開くと、アプリのように全画面で表示されます。

## 公開前にやること

- `index.html` の `AD_TAG` を、本番の広告ユニットのタグに差し替える（今はテスト用）
- 開発用の切り替えは `?dev=1` を付けたときだけ表示される。公開後も残すかどうか決める
- 課金を始める前に、プライバシーポリシーと特定商取引法の表記を用意する

## 注意

- 写真は保存されません。記録と設定は端末のブラウザ（localStorage）に保存されるため、ブラウザのデータを消すと記録も消えます。
- 機種変更や別のブラウザでは記録が引き継がれません。
